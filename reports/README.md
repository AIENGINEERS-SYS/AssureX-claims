# AssureX Reports

This directory contains competition/reporting deliverables grounded in the current AssureX repository.

## Files

- `project_report.md` — project report covering problem, architecture, data, models, rules, testing, security, privacy, limitations and future work.
- `python_model_evaluation_report.md` — algorithm comparison, held-out metrics, confusion matrix and model limitations.
- `model_prediction_confidence_comparison_report.md` — required comparison-report structure plus 30 real Python unseen-test baseline records; GTM paired evidence is explicitly marked pending rather than fabricated.
- `requirements_traceability.md` — maps SRS deliverables to repository evidence and identifies remaining gaps.

## Important distinction

These are **submission/evidence reports**. They do not mean the application already has a downloadable end-user report/export feature. The current README correctly states that the access-controlled PDF/CSV claim-report export feature is not yet implemented.

The final competition submission should regenerate reports whenever the final dataset, GTM model, Python model, policy version or evaluation logic changes.
